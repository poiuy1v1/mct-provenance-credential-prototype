# Contributing

This repository is a synthetic supplementary-software prototype accompanying a manuscript, not a production blockchain or financial-token project.

Before making changes:

1. Preserve the non-financial, non-transferable credential framing.
2. Do not add ERC-20 transferability, financial functions, liquidity pools, price logic, investment language, or deployed-chain claims.
3. Keep example data synthetic unless explicit consent, ethics review, and repository policy permit otherwise.
4. Run `bash scripts/run_smoke_tests.sh` before creating a release.

For manuscript-linked releases, update `CHANGELOG.md`, `RELEASE_NOTES_v0.3.0-alpha.md`, `CITATION.cff`, `.zenodo.json`, and `MANIFEST.md` consistently.
