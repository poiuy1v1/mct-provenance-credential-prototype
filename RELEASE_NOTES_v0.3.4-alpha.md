# v0.3.4-alpha

This release reconciles the synthetic diagnostic score to the executable value
`23.0324`, adds canonical event ordering, strengthens notebook execution/output
regression and negative tests, regenerates deterministic artifacts from clean
directories, rejects non-portable or escaping input paths, uses a real
`nbclient` committed snapshot, validates package manifests/checksums, and
finalises release-facing metadata.

The complete validation workflow passed on both Ubuntu and Windows through
GitHub Actions, including genuine `nbclient` notebook execution and deterministic
output comparison.

All data remain synthetic. The software is non-financial, non-transferable and
non-ranking, and it does not perform scientific validation.
