# Release notes - v0.3.2-alpha

Metadata-cleanup release for the synthetic, non-financial MCT provenance credential prototype.

This release preserves the same research-software prototype logic as v0.3.1-alpha and changes only repository/Zenodo-facing wording so that the public software metadata is less likely to be misread as a financial token, cryptocurrency, investment product, or deployable governance platform.

## Changes

- Updated `.zenodo.json` title to: `MCT provenance credential prototype for AI-ready MOF data`.
- Updated `CITATION.cff` version to `0.3.2-alpha`.
- Updated README and release documentation to describe this as a metadata-cleanup release.
- Replaced residual high-risk legacy full-name MCT metadata phrases in software-facing files with `MCT provenance credential` wording where this does not change the scientific concept.
- Preserved the synthetic dataset, Python simulation logic, notebook, Solidity stub, output files, and smoke-test workflow.

## Scope boundary

This package is a research-software prototype only. It is not a deployed blockchain, financial token system, cryptocurrency, investment product, or production governance platform.
